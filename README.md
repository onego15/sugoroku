# 双六不動産投資ゲーム

桃太郎電鉄風のブラウザベースボードゲームです。

## 遊び方

1. プロジェクトをクローン
2. `npm start` または `python3 -m http.server 8000` でローカルサーバーを起動
3. ブラウザで `http://localhost:8000` にアクセス

## ゲームルール

### 勝利条件
設定年数終了時の「総資産」が最大のプレイヤーが勝利
- 総資産 = (現金 + 所有物件価格) - 借金

### 基本進行（1ターン＝1ヶ月）
1. サイコロを振って移動
2. 止まったマスのイベント処理
3. カード使用（任意）
4. 決算（3月のみ）

### マスの種類
- **青マス**: 収入がもらえる
- **赤マス**: 支出が発生
- **黄色マス**: カードを入手
- **プラス駅**: 物件購入、臨時収入
- **マイナス駅**: 支出、悪行

### 目的地と貧乏神
- 目的地に最速で到着すると高額援助金
- 目的地から最も遠いプレイヤーに貧乏神が取り憑く
